Typermonitor

Monitoring profili ZawódTyper przez GitHub Actions.

Jak dodać profil

Otwórz data/profiles.json w repozytorium GitHub i dodaj obiekt:

{"url":"https://zawodtyper.pl/typer/6560/","enabled":true}

Ustaw enabled na false, aby wyłączyć profil. Po zapisaniu zmiany monitoring obejmie go w kolejnych uruchomieniach.

Historia

Wykryte identyfikatory komentarzy i data ostatniego sprawdzenia są przechowywane w data/monitor_state.json.

Logi

W repozytorium wejdź w Actions → Typermonitor — sprawdzanie profili, aby sprawdzić wynik kolejnego uruchomienia.

GitHub Actions nie jest serwerem działającym bez przerwy. Harmonogram cron uruchamia zadanie co 5 minut, ale GitHub może opóźniać start. Parser wymaga testu na żywym HTML profilu.
